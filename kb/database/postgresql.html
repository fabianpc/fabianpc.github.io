Instalacion en Debian 11

Instalacion de la ultima version para el sistema operativo

$ sudo apt search postgresql (opcional) $ sudo apt install postgresql

Revisar que este arriba el demonio

$ pg_isready

$ systemctl status postgresql

Operaciones de control

# systemctl start postgresql
# systemctl restart postgresql
# systemctl stop postgresql
# systemctl reload postgresql

Configuracion de seguridad basica

$ sudo passwd postgres
$ su - postgres
$ psql -c "ALTER USER postgres WITH PASSWORD 'contraseña_segura';"
(tambien se puede cambiar con psql --> postgres=# \password postgres)
$ exit

$ sudo vi /etc/postgresql/13/main/pg_hba.conf

$ sudo systemctl restart postgresql

Creacion de la base de datos

$ su - postgres
$ psql

$ psql -d sampledb -U userdb -W

Exportacion / Importacion

$ su - postgres
$ pg_dump -U postgres -d sourcedb -f sourcedb.sql (... crear la base de datos destino -> targetdb)
$ psql -U postgres -d targetdb -f sourcedb.sql
